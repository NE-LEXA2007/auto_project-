Прогнозирование цен подержанных автомобилей

**Реализация алгоритмов регрессионного анализа данных для оценки рыночной стоимости транспортных средств на основе технических характеристик и региональных факторов.**

---

## Обзор проекта
Целью данной работы является разработка прогностической модели на базе **Ridge Regression (Гребневая регрессия)**, которая способна предсказывать стоимость автомобиля. Проект решает задачу обработки разнородных данных (категориальных и числовых) и минимизации среднеквадратичной ошибки прогноза.

---

## Ключевые этапы реализации

### 1. Очистка данных (Outlier Handling)
Применение статистического метода **межквартильного размаха (IQR)** для фильтрации аномальных цен. Это позволяет исключить влияние экстремально дешевых или дорогих автомобилей на обучение модели.

### 2. Предобработка признаков (Feature Engineering)
* **One-Hot Encoding:** Преобразование текстовых данных (`Brand_Model`, `Engine_Type`, `Condition`, `Region`) в цифровой формат.
* **Standard Scaling:** Масштабирование числовых признаков (`Year`, `Mileage`) для приведения их к единому диапазону, что критично для работы алгоритмов с регуляризацией.
* **ColumnTransformer:** Использование конвейера для одновременной обработки разных типов столбцов.

### 3. Моделирование
Обучение модели **Ridge (L2-регуляризация)**. Выбор данного алгоритма обусловлен его устойчивостью к мультиколлинеарности (например, сильной связи между годом выпуска и пробегом) и защитой от переобучения.

### 4. Валидация и оценка
* Оценка точности с помощью метрик **MSE (Mean Squared Error)** и **$R^2$ (Коэффициент детерминации)**.
* Сравнение первых 6 предсказанных значений с фактическими для наглядной проверки работы модели.

### 5. Визуализация
* Построение **boxplot** для анализа распределения цен до и после обработки выбросов.
* Визуализация разброса фактических и предсказанных цен (**scatter plot**).
* Построение **гистограммы распределения ошибок** для проверки нормальности остатков.

---

## Результаты
Разработанная модель позволяет с высокой точностью оценивать ликвидность автомобиля на вторичном рынке. Использование регуляризации позволило добиться стабильных результатов даже на данных с большим количеством категориальных переменных.
